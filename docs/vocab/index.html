คำศัพท์ TOEIC ที่ออกบ่อย

คำที่ออกบ่อยแยกตามหมวด พร้อมความหมาย ตัวอย่างประโยค และการแยกชนิดคำจากคำลงท้าย แตะคำภาษาอังกฤษเพื่อฟังเสียงอ่าน

ไปที่หมวด
วิธีใช้ลิสต์นี้Top 100 คำที่ต้องรู้ก่อนสอบออฟฟิศ การประชุม และเอกสารบุคคล การรับสมัครงาน และการฝึกอบรมการเงิน บัญชี และสัญญาการตลาด การขาย และลูกค้าสินค้า การผลิต การสั่งซื้อ และการขนส่งการเดินทาง โรงแรม ร้านอาหาร และงานอีเวนต์อาคาร สถานที่ และการซ่อมบำรุงคำกริยา คำคุณศัพท์ และคำวิเศษณ์ที่ออก Part 5 บ่อยการแยกชนิดคำ (Parts of Speech)Collocations และ phrasal verbsคำที่หน้าตาคล้ายกันและสับสนบ่อยคำที่ข้อสอบชอบเปลี่ยนเป็นคำอื่น (paraphrase)

ไม่พบคำนี้ ลองพิมพ์ส่วนหนึ่งของคำ หรือค้นเป็นภาษาไทย

วิธีใช้ลิสต์นี้

ถ้ามีเวลาน้อย ให้ทวน Top 100 ก่อน แล้วค่อยไล่หมวดตามเรื่องที่ข้อสอบชอบออก

  • Top 100 เรียงตามความถี่จาก TOEIC Service List (TSL) เวอร์ชัน 1.1 ของ Browne & Culligan ซึ่งนับคำจากเอกสารเตรียมสอบ TOEIC ราว 1.5 ล้านคำ เลขอันดับคืออันดับในลิสต์นั้น

  • TSL ไม่นับคำธุรกิจพื้นฐาน เช่น order, schedule, available เพราะอยู่ในอีกลิสต์หนึ่ง (NGSL) แต่คำพวกนี้ออกบ่อยมาก จึงเติมไว้ในหมวดต่าง ๆ ด้วย

  • ตัดคำในคำสั่งข้อสอบ (infer, distractor) และคำง่ายที่น่าจะรู้แล้ว (airport, sandwich) ออก

  • ความหมายภาษาไทยและตัวอย่างประโยคทั้งหมดเขียนขึ้นใหม่ ไม่ได้มาจาก TSL

  • ตัวย่อ: n. คำนาม · v. คำกริยา · adj. คำคุณศัพท์ · adv. คำวิเศษณ์ · prep. คำบุพบท

การแยกชนิดคำ (Parts of Speech)

ดูคำลงท้ายก็เดาชนิดคำได้เกือบทุกครั้ง แม้ไม่รู้ความหมาย ใช้คู่กับตาราง "ช่องว่างอยู่ตรงไหน" ในหน้าทริก Part 5 จะตอบข้อชนิดคำได้เร็วมาก แต่มีข้อยกเว้นบางคำที่ข้อสอบชอบเอามาหลอก จึงใส่ไว้ในหมายเหตุด้วย

คำนาม (Noun) = ชื่อสิ่งของ เรื่อง หรือคน

คำลงท้ายตัวอย่างหมายเหตุ
-tion / -sioninformation, decision, extensionพบบ่อยที่สุด
-mentpayment, agreement, management
-nessbusiness, awareness
-ity / -tyquality, availability, safety
-ance / -enceperformance, attendance, conference
-ancy / -encyvacancy, efficiency
-uredeparture, procedure, signature
-shipmembership, partnership
-ageshortage, storage, package
-al (บางคำ)approval, renewal, arrival, proposalปกติ -al เป็นคำคุณศัพท์ แต่ 4 คำนี้เป็นคำนาม

คำนามที่เป็นคน ข้อสอบชอบให้เลือกระหว่าง "คน" กับ "สิ่งของ" ที่เป็นคำนามทั้งคู่ เช่น applicant (ผู้สมัคร) กับ application (ใบสมัคร) ถ้าประโยคพูดถึงคนที่มาสัมภาษณ์ ต้องตอบ applicant

คำลงท้ายความหมายตัวอย่าง
-er / -orผู้ทำmanager, employer, supervisor, visitor
-eeผู้ถูกกระทำ หรือผู้รับemployee, trainee, attendee

-ist / -ianผู้เชี่ยวชาญ ผู้ประกอบอาชีพspecialist, pharmacist, technician, librarian

-ifyverify, notify, qualify
-ateestimate, evaluate, coordinateระวัง accurate, fortunate เป็นคำคุณศัพท์ ส่วน candidate, certificate เป็นคำนาม
-enwiden, shorten, strengthen
en- (นำหน้า)enable, ensure, enlargeแปลว่า ทำให้

คำคุณศัพท์ (Adjective) = บอกลักษณะของคำนาม

คำลงท้ายตัวอย่างหมายเหตุ

-ary / -orytemporary, necessary, mandatory
-ed / -inginterested / interesting, satisfied / satisfying-ed = คนที่รู้สึก ส่วน -ing = สิ่งที่ทำให้รู้สึก เช่น The guests were satisfied. / The results were satisfying.

คำวิเศษณ์ (Adverb) = ขยายกริยา คำคุณศัพท์ หรือทั้งประโยค

ส่วนใหญ่คือ คำคุณศัพท์ + ly เช่น quick → quickly, careful → carefully, approximate → approximately

ข้อยกเว้นตัวอย่าง
ลงท้าย -ly แต่เป็นคำคุณศัพท์friendly, costly, timely, likely, lovely
เป็นได้ทั้งคำคุณศัพท์และคำวิเศษณ์daily, weekly, monthly, early, fast, hard
คำวิเศษณ์ที่ไม่ลงท้าย -lysoon, well, often, still, already
เติม -ly แล้วความหมายเปลี่ยนhard = หนัก / hardly = แทบจะไม่ · late = สาย / lately = ช่วงนี้

คำเชื่อมระหว่างประโยคhowever, therefore, in additionขึ้นต้นประโยคใหม่ แล้วตามด้วยจุลภาค
คำบอกจำนวน (Determiner)a, the, each, every, many, much, fewคำนาม (each / every + เอกพจน์ · many / few + พหูพจน์)

คำที่หน้าตาคล้ายกันและสับสนบ่อย

ข้อสอบชอบใส่คำที่สะกดคล้ายกันไว้ในตัวเลือกเดียวกัน ถ้าอ่านเร็วเกินไปจะเลือกผิดทันที

คู่คำต่างกันอย่างไรตัวอย่าง
adopt / adaptadopt = นำมาใช้ · adapt = ปรับให้เหมาะWe adopted a new system and adapted it to our needs.
affect / effectaffect = กริยา ส่งผลต่อ · effect = คำนาม ผลThe rain affected sales. The rule takes effect today.
considerable / considerateconsiderable = มาก · considerate = เอาใจใส่คนอื่นIt took considerable time. He is very considerate.
economic / economicaleconomic = เกี่ยวกับเศรษฐกิจ · economical = ประหยัดeconomic growth / an economical car
personal / personnelpersonal = ส่วนตัว · personnel = บุคลากรpersonal items / authorized personnel only
stationary / stationerystationary = อยู่กับที่ · stationery = เครื่องเขียนa stationary bike / a stationery store
complement / complimentcomplement = เสริมกัน · compliment = คำชม (complimentary = ฟรี)The wine complements the meal. Thanks for the compliment.
rise / raiserise = เพิ่มขึ้นเอง ไม่มีกรรม · raise = ทำให้สูงขึ้น มีกรรมPrices rose. They raised prices.
lend / borrowlend = ให้ยืม · borrow = ขอยืมCan you lend me a pen? Can I borrow your pen?
ensure / assure / insureensure = ทำให้แน่ใจ · assure = ยืนยันกับคน · insure = ทำประกันI assure you we will ensure quality.
principal / principleprincipal = หลัก สำคัญสุด · principle = หลักการthe principal reason / accounting principles
access / assessaccess = เข้าถึง · assess = ประเมินaccess the files / assess the damage
expand / extendexpand = ขยายขนาด · extend = ขยายเวลาหรือความยาวexpand the store / extend the deadline
remind / rememberremind = เตือนคนอื่น · remember = จำได้เองRemind me to call her. I remember her name.
advice / adviseadvice = คำนาม นับไม่ได้ · advise = กริยาShe gave me advice. She advised me to wait.
thorough / throughthorough = ละเอียดถี่ถ้วน · through = ผ่านa thorough check / walk through the park
quite / quietquite = ค่อนข้าง · quiet = เงียบIt's quite late. The library is quiet.
later / latterlater = ทีหลัง · latter = อย่างหลัง (จาก 2 อย่าง)Call me later. I prefer the latter option.
successful / successivesuccessful = ประสบความสำเร็จ · successive = ติดต่อกันa successful launch / three successive wins
respective / respectablerespective = ของแต่ละคน · respectable = น่านับถือThey returned to their respective offices.
sensible / sensitivesensible = มีเหตุผล · sensitive = อ่อนไหวa sensible plan / sensitive information
beside / besidesbeside = ข้าง ๆ · besides = นอกจากSit beside me. Besides tea, we have juice.
despite / althoughdespite + คำนาม · although + ประโยค (ความหมายเหมือนกัน)despite the rain / although it rained
during / whileduring + คำนาม · while + ประโยคหรือ V-ingduring the meeting / while I was waiting
by / untilby = ภายใน (ทำให้เสร็จก่อน) · until = จนถึง (ทำต่อเนื่อง)Submit it by Friday. The store is open until nine.
for / sincefor + ระยะเวลา · since + จุดเริ่มต้นfor ten years / since 2016
